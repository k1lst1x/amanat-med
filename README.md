# Amanat Med — MVP

Демонстрационный MVP прозрачной платформы адресной медицинской помощи в Кыргызстане.

## Что уже работает

- адаптивный интерфейс приложения и веб-режим;
- переключение русского и кыргызского языков;
- карточки сборов с целями и прогрессом;
- демонстрация двойной проверки документов;
- детализация расходов и журнал транзакций;
- список доноров и анонимная помощь;
- демонстрационный сценарий платежа без списания денег;
- истории завершённых сборов;
- генерация карточки и системный Share Sheet;
- прямые ссылки на карточки через параметр `?case=1`;
- публикация как статический сайт на GitHub Pages.

> Все имена, истории, суммы и документы в MVP вымышлены. Сайт не принимает реальные платежи.

## Локальный запуск

Можно просто открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8080
```

После этого открыть <http://localhost:8080>.

## Публикация на GitHub Pages

1. Откройте эту папку в GitHub Desktop.
2. Нажмите **Publish repository** и выберите публичный репозиторий.
3. На GitHub откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

GitHub покажет адрес сайта после завершения публикации. Обычно это занимает несколько минут.

## Перед реальным запуском

Для настоящего благотворительного сервиса потребуется отдельный защищённый backend: проверка личности и клиник, хранение медицинских документов с контролем доступа, платёжный провайдер, согласия на обработку персональных данных, аудит операций и юридическая проверка требований Кыргызстана.
